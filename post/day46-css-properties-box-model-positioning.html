1.常用CSS属性

1.1 字体属性 font

font-family(字体)

font-size（大小）

font-style（风格）

—- normal标准样式

—- italic斜体

—- oblique倾斜

—- inherit从父类继承的字体样式

font-weight(字体加粗)

–normal标准样式

—-bold粗体

—-bolder更粗

—-lighter更细

1.2 文本属性 text

letter-spacing(字母间隔)

text-decoration（划线修饰）

去除超链接下划线：text-decoration: none;

text-align（文本对齐方式）

—-left向左对齐

—-center居中

—-right向右对齐

text-indent(文本缩进)

line-height（行高）

1.3 背景 background

background-color(背景色)

background-image(背景图)

background-repeat(平铺方式)

background-attachment(背景图固定)

—-fixed

1.4 边框 border

border-bottom

—-solid(实线)

—-dashed(虚线)

—-double(双实线)

border-width

border-style

border-color

border-image

border-radius

注意：单行文字垂直居中：行高属性值等于盒子高度属性值

2.盒子模型 div

2.1 构成

CSS 盒子模型规定了元素框处理元素内容、内边距、边框和外边距的方式。

内容区域 – width & height

内边距 – padding(出现在内容与盒子边缘之间，添加 padding 会撑大盒子）

边框线 – border

外边距 – margin(出现在盒子外面，拉开两个盒子之间的距离)

注意：

装饰顺序：上右下左

能不使用内边距就不使用，因为会把盒子撑变形，一句话，能用外边距就用外边距

****div水平居中*：***margin: 0 auto;

3.定位 position

属性：relative(相对定位)、absolute(绝对定位)、fixed(固定定位)

边偏移：设置盒子的位置：left/ right/ top/ bottom

3.1 CSS 定位机制

CSS 有三种基本的定位机制：普通流、浮动和绝对定位

除非专门指定，否则所有框都在普通流中定位。也就是说，普通流中的元素的位置由元素在 (X)HTML 中的位置决定

块级框从上到下一个接一个地排列，框之间的垂直距离是由框的垂直外边距计算出来

定位的基本思想很简单，它允许你定义元素框相对于其正常位置应该出现的位置，或者相对于父元素、另一个元素甚至浏览器窗口本身的位置

3.2 相对定位 relative

相对定位：相对于原有的位置发生改变，并且保留原有的空间位置

特点：

相对定位：保留原有位置，相对于原有位置进行位移

3.3 绝对定位 absolute

绝对定位相对于他有position属性的父级元素进行定位，如果父级元素没有postion定位，那么就找父级的父级，直到向上找到position定位为止，如果他向上找不到position定位，那么就以最外层的body进行定位。并且绝对定位不会保留原有的位置空间

特点：

不保留原有位置，向上找寻父级标签，判断父级标签是否有position属性，如果有就按照父级标签进行位移，如果没有就继续向上找寻父级标签，直到body标签为止，就按照body标签进行位移

注意：

子绝父相（子元素绝对定位，父元素进行相对定位）：如果需要对某个元素进行绝对定位的时候，一般先给父元素加相对定位

3.4 固定定位 fixed

场景：将元素固定到页面的某个位置，元素的位置在网页滚动时不会改变，eg：置顶框

特点：

不占位置，设置边偏移相对浏览器窗口改变位置

4.浮动

属性：

float: left; 向左浮动

float: right; 向右浮动

作用：

1.浮动元素脱离文档流(默认的排布规则)

2.用来制作菜单栏

特点：

1.浮动后的盒子****顶对齐****

2.浮动后的盒子具备****行内块****特点（用一行，可以设置宽高）

3.浮动后的盒子****脱标*，*不占用标准流的位置****

副作用：因为浮动会使元素脱离了标准的文档流，从而导致父级元素无法被撑开。

解决办法：添加空盒子

在被浮动的元素后面，添加一个空的div，并且设置一个clear类，并付给该div

.clear{clear:both;} 清除浮动效果

注意：消除浮动带来的影响：父容器高度坍塌、浮动造成布局混乱【面试BFC】

5.扩展

5.1 圆角 border-radius

作用：设置元素的外边框为圆角

属性值：数字+px / 百分比

提示：属性值是圆角半径

正圆形状：给正方形盒子设置圆角属性值为 *宽高的一半 / 50%*

5.2 盒子阴影 box-shadow

作用：给元素设置阴影效果

属性值：X 轴偏移量 Y 轴偏移量 模糊半径 扩散半径 颜色 内外阴影

eg:box-shadow: 10px 10px 5px gainsboro; 添加按钮阴影 X轴偏移量 Y轴偏移量 阴影模糊半径

注意：

1.X 轴偏移量 和 Y 轴偏移量 必须书写

2.默认是外阴影，内阴影需要添加 inset

3.文字阴影也是相似的：text-shadow: 5px 5px 5px black; 添加文本阴影 X轴偏移量 Y轴偏移量 阴影模糊半径

运行结果：

5.3 元素显示方式 display

属性：

1.block块元素（可以设置宽高）

2.inline行内元素（不能设置宽高，共用一行）

3.inline-block行内块元素（用一行，可以设置宽高）

注意：

1.none 让元素消失 扩展：元素消失

2.display:none(文档空间消失)

3.color:rgb(0,0,0,0) 完全透明

4.opacity:0 完全透明

5.visibility:hidden 元素不可见（空间还在）

5.3.1 块级元素 block

独占一行

宽度默认是父级的100%

添加宽高属性生效

5.3.2 行内元素 inline

特点：

一行可以显示多个

设置宽高属性不生效

宽高尺寸由内容撑开

5.3.3 行内块元素 inline-block

特点：

一行可以显示多个

设置宽高属性生效

宽高尺寸也可以由内容撑开

5.4 元素溢出 overflow

作用：控制溢出元素的内容的显示方式

hidden：溢出隐藏

scroll：溢出滚动(无论是否溢出，都显示滚动条位置)

auto：溢出滚动(溢出才显示滚动条位置)

5.5 堆叠层级 z-index

z-index属性，确定层级大小，用来设定哪一个盒子在上面，越大越在上面

默认效果：按照标签书写顺序，后来者居上

作用：设置定位元素的层级顺序，改变定位元素的显示顺序

属性值：*整数数字*（默认值为0，取值越大，层级越高）

5.6 清除标签默认的样式

注意：文字一般使用span标签包裹，这样方便css设置样式
