day07

1.特殊的流程控制语句

分类：break，continue，return，label

1.1 break

理解：作用在循环中，表示跳出整个循环语句

1.2 continue

理解：作用于循环中，表示跳过循环体剩余的部分，进入到下一次循环

1.3 return

理解：作用于方法中，表示结束该方法

1.4 label

理解：给循环做标记
面试题：描述下列代码的运行结果
答：运行结果循环5遍 1 2 3 4 5 (不会报错)

需求：嵌套for循环，外层循环5次，内层循环3次，当外层循环到第3次时，在内层循环中结束掉外层循环

在 Java 中，如何跳出当前的多重嵌套循环？
答：
在最外层循环前加一个标记如 a，然后用 break a;可以跳出多重循环。

2. 方法

概念：特定功能的代码块

好处：减少了代码的冗余

分类：

无参数无返回值的方法

带参数的方法

带返回值的方法

理解：

参数是方法调用时传入的数据

方法写在类里

方法必须被调用，不然永远是个摆设

实参与形参的个数必须一致，并且类型必须兼容
