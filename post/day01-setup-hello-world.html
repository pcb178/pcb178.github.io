从零开始搭建 Java 开发环境，配置JAVA_HOME和Path环境变量，编写并运行第一个 Hello World 程序，理解 JavaEE 基础概念，还涵盖Java特点、类文件限制、字节码定义，以及JVM、JDK、JRE的关系等基础内容。

Day01 搭建环境，编写hello world

1.软件开发基础

1.1 什么是JavaEE

接收到客户端的请求，并通过响应返回给客户端数据的技术

1.2 常有的开发语言

C/C++：嵌入式

HTML、CSS、JavaScript、JQuery、VUE、BootStrap：网页

Java：移动端、服务器、数据库

Python：数据分析

2.Java开发环境搭建

2.1 什么是JDK和JRE

目的：写Java代码

工具：JDK(Java开发工具包)

环境：JRE(Java运行时环境)

2.2 安装JDK

注意：

1.如果你仅仅运行Java程序，只用安装JRE即可，但是你要编写Java程序，就必须安装JDK和JRE，所以JDK安装中包含了JRE

2.安装路径建议用默认路径

3.如果使用自定义路径，路径中不要使用中文

4.安装后不会像QQ有开启软件的图标

5.如果你安装了JDK和JRE，建议卸载后重新安装（控制面板->程序->删除程序）

2.3 配置环境变量

目的：让当前系统能够识别到Java的运用程序

位置：计算机/此电脑 右键 -> 属性 -> 高级系统设置 -> 高级卡页 -> 环境变量

当前用户变量 和 系统变量 的区别：

在当前用户变量配置的信息，只能在当前用户上使用

在系统变量配置的信息，切换用户后也可以使用

配置信息：JAVA_HOME、Path

注意：

1.JAVA_HOME一般是没有的，需要新建，Path是有的不需要新建

2.Path中可能会存在多个路径，多个路径之间使用英文的;作为分隔符

变量名 变量值
JAVA_HOME C:\Program Files\Java\jdk1.9.0_144
Path %JAVA_HOME%\bin

打开的系统的控制台/cmd/黑窗口/命令行：搜索cmd（按键盘win+r,弹出运行界面，输入“cmd” ）

输入：

注意：

1.如果出现“不是内部或外部命令”，证明配置失败，原因是Java_HOME或Path的路径配置错误

2.出现配置失败，修改了路径后，重新启动cmd

3.编写第一个Java程序

命令 描述
cd/ 退回到根目录
d: 跳转到指定D盘符
cd 文件夹名 进入到指定文件夹
cls 清空cmd命令
dir 遍历该文件夹下所有的文件

3.2 在记事本编写Java源程序

注意：下面的java源文件的扩展名是Hello.java

3.3 在cmd命令窗口编译、执行

javac Hello.java – 编译：将.java文件编译成.class文件

java Hello – 运行：运行.class文件

总结：先编译，再运行

javac是将源程序.java编译成.class文件

java是将字节码转换为机器码文件执行

3.4 程序编译执行过程

1.Java语言有哪些特点

简单易学（Java语言的语法与C语言和C++语言很接近）

面向对象（封装，继承，多态）

平台无关性（Java虚拟机实现平台无关性）

支持网络编程并且很方便（Java语言诞生本身就是为简化网络编程设计的）

支持多线程（多线程机制使应用程序在同一时间并行执行多项任务）

健壮性（Java语言的强类型机制、异常处理、垃圾的自动收集等）

安全性

2.一个”.java”文件中可以包括多个类？有什么限制？

可以有多个类，但只能有一个public类，并且public类的类名必须和文件名相同

3.什么是字节码？

字节码：Java源代码经过虚拟机编译器编译后产生的文件(即.class的文件)，它不面向任何特定的系统，只面向虚拟机

4.JVM，JDK，JRE的关系

JDK：Java开发工具包

JRE：Java运行时环境

JVM：Java虚拟机， 可以在不同的操作系统上执行Java字节码。JVM的主要作用是将Java源代码编译成字节码

JDK包含JRE (java运行环境)，包含JVM (java虚拟机)

5.面向过程是具体化的，流程化的，解决一个问题，你需要一步一步的分析，一步一步的实现

面向对象是模型化的，你只需抽象出一个类，这是一个封闭的盒子，在这里你拥有数据也拥有解决问题的方法。需要什么功能直接使用就可以了，不必去一步一步的实现，至于这个功能是如何实现的，管我们什么事？我们会用就可以了

面向对象的底层其实还是面向过程，把面向过程抽象成类，然后封装，方便我们使用的就是面向对象了
